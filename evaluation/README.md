# evaluation

Every number in the technical report is regenerated by a script here.

```
dataset_v0/          W1-W2 replay fixtures + hand-labeled events (manifest.json)
scripts/             make_dataset_v0.py (synthetic renders), eval_dataset_v0.py (rep F1, NHPT MAE)
results/             generated tables (dataset_v0.md, dataset_v0.json)
failure_cases/       clips + notes for every miss
```

**dataset_v0 honesty note.** The `synthetic_*` entries are rendered with OpenCV from the board
spec (labeled `"synthetic": true` in the manifest and in the trace). They validate the pipeline
end to end but say nothing about real lighting, hands, or pegs. Real recordings
(`real_*`, ≥ 1 pegboard 20-rep + 1 NHPT run) are required before Checkpoint B is fully met;
see docs/RISKS.md.

```bash
cd services/session
uv run python ../../evaluation/scripts/make_dataset_v0.py     # regenerates synthetic_*.mp4 + manifest
uv run python ../../evaluation/scripts/eval_dataset_v0.py     # writes results/dataset_v0.{md,json}
```
