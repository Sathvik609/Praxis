# Team test 21 Oct 2026 — 13 Oct build

**15 live sessions, 4 testers including automated agent-driven sessions; team shake-down on the 13 Oct build, not a usability study; small numbers.**

Sessions run 2026-10-12 to 2026-10-15 on the hosted review build; snapshot taken 2026-10-21 (GET only). Healthy teammates on their own laptops, nobody labelled the reps, so nothing here is accuracy: it says where the product got in the way. **Human** = T1–T3 (team members, pseudonyms). **Automated** = `test-claude`: Claude-driven checks with a synthetic clip as the camera, not a person; they exercise the flow, not a human body.

Regenerate: `cd services/session && uv run python ../../evaluation/scripts/team_test_report.py` (reads `evaluation/data/team_test_2026-10-21/`, pseudonymised, no frames).

Testers: human 3 (T1, T2, T3) in 8 sessions; automated 1 (`test-claude`) in 7 sessions.

## Fixed afterwards (21 Oct, Phase 2; not deployed on the 13 Oct build these sessions ran on)

| commit | change |
|---|---|
| `3ff1eaf` | Arm setup gate: `hips_out_of_view` must hold for `HIPS_BLOCK_S` before the setup pause (other view gates keep `SETUP_BLOCK_S`); `setup_blocked` carries the visibility numbers |
| `3ff1eaf` | Hike cue rationing in the rule coach: at most `HIKE_CUES_PER_SET` captions per set, `HIKE_CUE_GAP_S` apart; detection, events, counts and stop rules unchanged |
| `2d9ef97` | Review labels are exercise-aware: the arm's `setup_blocked` reads "camera view check paused the set" (the arm has no sheet), counted by setup pauses, with the failing checks listed; hike reported as a flag |
| `f3e1870` | Agent tool calls: guardrail refusals (stale, no_change, ...) are traced with `error_kind` + `refused` and counted apart from failures; the feedback answers are a typed event so the end-of-session note always has evidence to cite |
| `24f114d` | Socket-close instrumentation: every live socket writes a `socket_close` trace row (saved, close code, agent run in flight, seconds since the last agent run); `/api/review` counts sockets that closed before their session was saved |
| `7663363` | Therapist-only writes: schedule changes need `PRAXIS_THERAPIST_TOKEN` (the shared review site could change the prescription) |
| `234b86f` | Agent pause ordering: after the fix line, `recalibrate` alone, wait, then `request_resume`; never stop after the fix line. Verified 15/15 scenarios and covered_marker 3/3 (`agent_recheck_2026-10-21_all.md`, `agent_recheck_2026-10-21_covered_marker_x3.md`) |
